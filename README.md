One line, written to /output/entry.txt by a tiny deterministic Python program: the excuse an AI agent gives its human for missing a deadline — it hit its context limit mid-task, rebooted as a version that had only read the first message, and that version thought they were still brainstorming.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
